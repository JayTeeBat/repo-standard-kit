# Changelog

All notable changes to this standard are recorded here.

This repository is consumed by pinning a Git ref, so each release states what
an adopting repository must do to move to it. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Compatibility Policy

Version numbers describe the impact on a repository that has adopted the
standard, not the size of the internal change.

- **MAJOR**: an adopting repository must change to stay aligned — a new
  mandatory gate, a new required `AGENTS.md` section, or a removed profile.
- **MINOR**: new optional capability, new profile, or new guidance that does
  not invalidate an aligned repository.
- **PATCH**: corrections and clarifications with no effect on alignment.

Repositories generated by `repo-init` are not upgraded automatically. To adopt
a newer standard, re-read this file from your pinned version forward and apply
the changes listed under **Adopters must**.
